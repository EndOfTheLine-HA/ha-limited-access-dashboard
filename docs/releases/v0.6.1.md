Fixes from the independent v0.6.0 review:

- Keep layouts, sessions and audit history when a dashboard URL name changes.
  Databases now use a stable configuration entry ID under Home Assistant's
  configured directory. Existing dashboard data is migrated on upgrade.
- Delete only verified dashboard databases inside the managed directory.
  Imported external databases are copied and retained, never deleted.
- Preserve unaffected owner and guest card placements when entities are removed.
  The owner editor lists approved entities that have not been placed yet.
- Show recent activity to the owner, include entities in custom-card audit rows,
  and record service failures. Bound JSON request sizes, including chunked bodies.
- Restore the stricter login/confirmation CSP, reject control characters in
  resource URLs, keep one-column layouts at tablet widths, and load card resources
  concurrently with one timeout window.
- Clarify the custom-card adapter's limitations and standalone security model.
- Build release archives in CI from tagged Git blobs with canonical line endings
  and fixed uncompressed ZIP metadata, avoiding OS/zlib differences.

Back up your HA configuration and `limited-access-dashboard-data` before updating.
Restart Home Assistant after updating through HACS. Previously orphaned files from
URL renames before this fix are not guessed at or deleted automatically.
Custom Lovelace/HACS support remains experimental and uses trusted same-origin
JavaScript. Private vulnerability reporting is now enabled in the repository.
