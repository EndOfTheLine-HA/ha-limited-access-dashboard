Fixes for guest dates set from Configure:

- Setting **Access begins** or **Access expires** in Configure no longer stops
  the dashboard from loading. Home Assistant's date picker sends a plain local
  time, which the dashboard refused ("expires_at must include a UTC offset"), so
  every guest page returned 404. Dates are now read in the dashboard's time zone.
  A dashboard already stuck this way loads again after the update, with nothing
  to re-save.
- Clearing a date in Configure now removes it. Before, the old date came back.
- The form shows saved dates at their real time instead of 12:00 AM, so saving
  the form again no longer moves an expiry to midnight.
- The form loads time zones off Home Assistant's event loop.
- No other setting, data or behavior changes: sessions, layouts and databases
  are untouched.

Back up HA before updating through HACS, then restart HA. If a guest's access has
already expired, set a new **Access expires** date in Configure.
