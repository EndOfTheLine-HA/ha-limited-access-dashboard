Blocking-call fixes from the HACS review:

- Loading a time zone no longer blocks Home Assistant's event loop. The first
  lookup of a zone reads tzdata from disk, so setup and the YAML import step now
  do it in an executor job.
- Removing a dashboard no longer checks for its database file on the event loop;
  that check runs in an executor job too.
- No setting, data or behavior changes: existing dashboards, sessions, layouts
  and databases are untouched.

Back up HA before updating through HACS, then restart HA.
